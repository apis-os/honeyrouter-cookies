# Download HoneyRouter Cookies

**Zip (Load unpacked):** https://omniroute.apisos.dev/extensions/honeyrouter-cookies-dist.zip

1. Download and unzip the archive
2. Chrome → `chrome://extensions` → enable **Developer mode** → **Load unpacked**
3. Select the unzipped folder (must contain `manifest.json`)
4. Open **Options** → paste a manage-scope admin token (base URL defaults to `https://omniroute.apisos.dev`)
5. Sign in at `chat.deepseek.com` — `userToken` auto-pushes to HoneyRouter
