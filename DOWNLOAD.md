# Download

Built extension zip (Load unpacked):

**https://omniroute.apisos.dev/extensions/honeyrouter-cookies-dist.zip**

1. Download and unzip
2. Chrome → `chrome://extensions` → Developer mode → Load unpacked
3. Select the unzipped folder
4. Options → paste manage-scope admin token (base URL defaults to `https://omniroute.apisos.dev`)
